# Quantum Search Analysis using Grover's Algorithm

The project focuses on:
- Building Grover circuits from scratch
- Simulating quantum search on small systems
- Comparing theoretical and experimental success probabilities
- Studying the impact of noise on quantum search performance
- Comparing quantum search with classical search complexity

## Current Status

- Grover implementation completed
- Probability analysis implemented

## Installation

Clone the repository:

```bash
git clone https://github.com/dolong226/Quantum-Search-Analysis-using-Grover-s-Algorithm
cd Quantum-Search-Analysis-using-Grover-s-Algorithm
```

## Install dependencies
```
pip install -r requirements.txt
```
